# Level 3 "Sunflare Ridge" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third, longest level ("Sunflare Ridge") featuring a new dashing enemy, a brighter BGM track, and an extra-life pickup.

**Architecture:** The game is 7 IIFE JS modules loaded via `<script>` tags (no build step, no node — validation happens in a browser via the existing Flask preview server at `http://127.0.0.1:5000/`). Level data lives in `levels.js` (pure data + builder helpers + `THEMES`). Behavior lives in `entities.js` (per-system update functions + shared `gameState`). Drawing lives in `renderer.js`. Orchestration lives in `game.js`. Music tracks live in `audio.js`. No template changes are needed (the HUD badge is set from `LEVELS[currentLevel].name` at runtime).

**Tech Stack:** Vanilla JS (ES6, IIFE globals), HTML5 Canvas, WebAudio. No libraries, no tests framework — the test harness is a standalone HTML page under the Flask static folder.

## Global Constraints

- No external assets, no npm/node, no build step — everything is hand-authored JS.
- All modules are IIFEs exposing globals: `Audio`, `Input`, `Levels`, `Entities`, `Renderer`; `Game` exposes only `window.__neon = { playLevel, loadLevel, start, player, enemies, projectiles }`.
- Scene arrays are reset by `Levels.clearScene()` and re-populated by `LEVELS[n].build()` via `loadLevel(n)`.
- Existing enemy kinds are `walker` (patrol), `flyer` (bob), `shooter` (aimed bolts); each is an object in `Levels.enemies` with `{ x, y, w, h, min, max, dir, speed, alive, kind }` plus kind-specific fields, updated in `updateEnemies(dt)` and drawn by a `drawEnemy` dispatch in `renderer.js`.
- Pickups are circle-rect collectibles: `{ x, y, r, taken }` in scene arrays, checked with `Entities.circleRect`, consumed by setting `taken = true`.
- `gameState.totalLevels` currently equals `2` and must become `3`; `onWin()` already auto-advances for `currentLevel < totalLevels` and shows the finale for the last level.
- `LEVEL_MAX_W = 5120` in `levels.js` must be bumped above the longest level width.
- HUD lives render as `"♥".repeat(lives) + "♡".repeat(3 - lives)`; `String.repeat` with a negative count yields `""`, so the HUD already extends past 3 hearts — cap the player's lives at 6 in code.
- Music tracks are objects in a private `TRACKS` map: `{ name, bpm, sub, bassType, leadType, bassVol, leadVol, steps }` where `steps` is an array of `[bassMidi, leadMidi]` pairs and `sub` is note subdivision (2 = eighth, 4 = sixteenth). `playMusic(trackNum)` starts the track; the game calls it via `beginMusic()` in `game.js`.
- Testing: run the harness at `/static/tests/level3_smoke.html` in the running preview server; it loads all modules against stub DOM and asserts on the exported globals and `window.__neon`. After each task, reload the page and confirm every line prints PASS and the browser console is clean.

- [ ] **Step 3: Add the darter behavior to `updateEnemies` in `entities.js`**

In `updateEnemies(dt)`, after the existing `flyer`/`shooter` branches and before the shared stomp/overlap block, add a fully self-contained darter branch that handles movement, stomp, and hurt, then `continue`s:
```js
if (e.kind === "darter") {
  const ecx = e.x + e.w / 2;
  const pcx = player.x + player.w / 2;
  if (e.state === "wait") {
    if (Math.abs(pcx - ecx) < 520) e.dir = pcx >= ecx ? 1 : -1;
    e.timer -= dt;
    if (e.timer <= 0) { e.state = "windup"; e.timer = 0.3; }
  } else if (e.state === "windup") {
    e.timer -= dt;
    if (e.timer <= 0) { e.state = "dash"; e.timer = e.dashDist; }
  } else {
    const move = e.dir * e.dashSpeed * dt;
    const nx = Math.max(e.min, Math.min(e.max - e.w, e.x + move));
    if (nx === e.x) { e.state = "wait"; e.timer = e.waitTime; }
    else {
      e.timer -= Math.abs(move);
      e.x = nx;
      if (e.timer <= 0) { e.state = "wait"; e.timer = e.waitTime; }
    }
  }
  if (player.invuln > 0) continue;
  if (overlap(player, e)) {
    const stompable = e.state === "wait";
    const stomping = player.vy > 120 && player.y + player.h - e.y < e.h * 0.7;
    if (stompable && stomping) {
      e.alive = false;
      player.vy = -JUMP_V * 0.62;
      gs.score += 50;
      sfx.stomp();
      burst(e.x + e.w / 2, e.y + e.h / 2, 12);
    } else {
      if (_onHurt) _onHurt();
    }
  }
  continue;
}
```
